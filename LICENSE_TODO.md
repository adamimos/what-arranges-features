# License: decision needed

The source repository (`adamimos/epsilon-transformers`) has no LICENSE file on any branch, so
there is nothing to inherit. Without a license, the code is "all rights reserved" by default
and others cannot legally reuse it.

Choose a license, add it as `LICENSE`, delete this file, and update the "License" section of
`README.md` and the `license` field in `CITATION.cff`. Common choices for research code are
MIT, BSD-3-Clause, or Apache-2.0. The Hugging Face dataset needs its own license (for
example CC-BY-4.0) in its dataset card.
